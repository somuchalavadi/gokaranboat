# Supplied photography

Place the real boat and experience photographs in this folder. Do not add promotional posters or generated images to the site.

Then set the matching `src` entries in `/lib/images.ts` to paths such as `/images/boat-hero.jpg`. Keep a slot empty until its real file is present; the site will show a labelled navy placeholder in that slot.

Use separate boat photos for the hero and boat feature when available. The four-angle design render belongs in the boat feature only when no real boat photo is available there.
